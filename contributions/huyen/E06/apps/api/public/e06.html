PHANTA / E06

POS bán lẻ · Quản lý ca thu ngân · Sổ kho — bảng thử nghiệm API trên máy cá nhân

Chế độ kiểm thử: Các nút sử dụng API thật, có thể thay đổi dữ liệu. Cần tài khoản có quyền CASHIER / MANAGER / ADMIN. E04 thanh toán và E16 báo cáo tổng hợp đang tạm tắt. Không sử dụng dữ liệu khách hàng thật.
Chưa kiểm tra kết nối.

1. Xác thực

Đăng nhập bằng số điện thoại, mật khẩu; nếu có bước OTP, xác minh OTP theo quy trình của hệ thống. Token chỉ giữ trong bộ nhớ trang, không lưu vào trình duyệt.

Chưa đăng nhập

2. Sản phẩm POS

GET /canteen/products — yêu cầu quyền thu ngân/quản lý.

Chưa tải dữ liệu.

3. Ca thu ngân

BR-44: một quầy chỉ được có một ca OPEN.

Chưa có yêu cầu

4. Thử API POS / Kho

Gửi JSON đến các API được cấp quyền. Các POST có thể tạo dữ liệu thật trong MongoDB.

Chưa gửi

Kiểm thử E06 – Kết quả

HTTP 401: chưa đăng nhập; 403: tài khoản không có quyền; 400: dữ liệu không hợp lệ; 200/201: yêu cầu được xử lý. Mã 200/201 vẫn cần kiểm tra dữ liệu và quy tắc nghiệp vụ.

Sẵn sàng.
